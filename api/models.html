API Data Models

Schemas for the Firebase HTTPS functions currently documented by HouseLearning. User profiles, lessons, and analytics are not exposed through a public HouseLearning REST API.

See the complete OpenAPI 3.1 specification

Models

Assistant request Assistant response Notification delivery Errors and authorization

Assistant request

The unauthenticated assistant HTTPS function accepts a JSON object with a non-empty message or prompt. Optional context fields include subject, grade, source URLs, and tutor mode.

Example

{
  "message": "Explain equivalent fractions.",
  "subject": "math",
  "grade": "Grade 5",
  "language": "en",
  "tutorMode": true
}

Assistant response

Successful assistant requests return generated text and a suggestions array.

Example

{
  "text": "Equivalent fractions name the same amount...",
  "suggestions": []
}

Notification delivery

The inbound notification-email function returns the number of recipient notifications created. Notification reads and updates use Firebase SDK operations protected by Firestore rules.

Example

{
  "ok": true,
  "recipientCount": 12
}

Errors and authorization

Error status codes and response formats are endpoint-specific; consult the OpenAPI specification. The notification image endpoint requires a Firebase ID token and returns media only to the notification recipient. The assistant endpoint is public and may incur model-provider usage.
